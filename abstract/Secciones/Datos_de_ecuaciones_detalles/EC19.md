Ecuación

3. Argumentos y derivación analítica de las variables

A. El Principio de Mínima Acción (Ecuación de Euler-Lagrange)
La primera parte, \delta S / \delta \phi = 0, indica que la evolución del campo \phi en el espacio-tiempo minimiza la acción total. Para un campo escalar en un espacio curvo, la ecuación de Euler-Lagrange es:

\frac{\partial \mathcal{L}}{\partial \phi} - \frac{1}{\sqrt{-g}} \partial_\mu \left( \sqrt{-g} \frac{\partial \mathcal{L}}{\partial (\partial_\mu \phi)} \right) = 0 

B. Derivación paso a paso
Tomando los términos relevantes del Lagrangiano total (Ecuación 16) que contienen a \phi:

1. Término cinético: \mathcal{L}_{\text{cin}} = \frac{1}{2} g^{\mu\nu} \partial_\mu \phi \partial_\nu \phi.
   · Derivada respecto a \partial_\mu \phi: g^{\mu\nu} \partial_\nu \phi.
   · Aplicando el operador diferencial: \frac{1}{\sqrt{-g}} \partial_\mu (\sqrt{-g} g^{\mu\nu} \partial_\nu \phi) \equiv \square \phi.
2. Término potencial: \mathcal{L}_{\text{pot}} = -V(\phi).
   · Derivada respecto a \phi: -\frac{\partial V}{\partial \phi}.
3. Término de acoplamiento QCD: \mathcal{L}_{\text{QCD}} = \frac{\phi}{f_\phi} G_{\mu\nu}^a G^{a\mu\nu}.
   · Derivada respecto a \phi: \frac{1}{f_\phi} G_{\mu\nu}^a G^{a\mu\nu}.

Sustituyendo todo en la ecuación de Euler-Lagrange y reorganizando los signos, obtenemos exactamente la Ecuación (19):

\square \phi + \frac{\partial V}{\partial \phi} = \frac{1}{f_\phi} G_{\mu\nu}^a G^{a\mu\nu} 

C. Interpretación del d'Alembertiano (\square)
En el límite de espacio-tiempo plano (sin gravedad), g^{\mu\nu} \to \eta^{\mu\nu} y \sqrt{-g} = 1, por lo que \square \phi \to -\partial_t^2 \phi + \nabla^2 \phi. Esta es la ecuación de onda estándar de Klein-Gordon.

D. El término fuente (Lado derecho)
A diferencia de la ecuación de Klein-Gordon libre (que tiene cero en el lado derecho), aquí el campo \phi está acoplado a la QCD. El término G_{\mu\nu}^a G^{a\mu\nu} es proporcional a la anomalía de traza de QCD. Físicamente, esto significa que la presencia de gluones (materia fuerte) actúa como una "carga" o fuente que modifica el valor del campo \phi, y viceversa.

---

4. Explicación de lo que dice la ecuación

La Ecuación (19) es la ecuación de movimiento del campo de la Deuda de Información.

Imagina que el campo \phi es como la superficie de un océano (el vacío cuántico). Si lo perturbas, genera ondas. La parte izquierda de la ecuación (\square \phi + \partial V/\partial \phi) describe cómo esas ondas viajan y cómo el potencial de doble pozo (la gravedad de la Deuda) intenta devolver el campo a su posición de reposo.

Sin embargo, la parte derecha de la ecuación dice que este océano no está aislado. El término G^2 (los gluones) actúa como el viento que sopla sobre el agua. Donde hay materia fuerte (protones, neutrones), los gluones "empujan" el campo \phi.

En pocas palabras: el vacío no es un ente pasivo; interactúa activamente con la materia. La fuerza nuclear fuerte genera una "presión" sobre la red topológica, obligando al campo \phi a reaccionar. Esta interacción es el mecanismo matemático que, en el manuscrito, permite derivar la masa de los bariones.

---

5. Resumen de todos los datos de la fórmula

· Tipo de ecuación: Ecuación diferencial parcial de segundo orden (Klein-Gordon con fuente).
· Variables independientes: Coordenadas espacio-temporales x^\mu.
· Variables dependientes: Campo escalar \phi.
· Parámetros: f_\phi (escala de decaimiento), parámetros del potencial V(\phi) (como \mathfrak{D}).
· Término fuente: \frac{1}{f_\phi} G_{\mu\nu}^a G^{a\mu\nu} (densidad de energía de gluones).
· Dimensionalidad: El operador \square \phi tiene dimensiones de densidad de energía. El lado derecho G^2/f_\phi también tiene dimensiones de densidad de energía.

---

Python

(Implementación simbólica con sympy para representar la ecuación diferencial y un ejemplo de solución numérica simplificada en 1D).

```python
import sympy as sp
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

# --- 1. Representación Simbólica ---
phi, f_phi, x = sp.symbols('phi f_phi x')
V = sp.Function('V')
# Representamos el operador d'Alembertiano como una derivada de segundo orden
# (simplificado a 1D espacial para visualización)
Box_phi = sp.diff(phi(x), x, 2) 
G_squared = sp.Symbol('G^2')

# Ecuación (19)
ec_19 = sp.Eq(Box_phi + sp.diff(V(phi), phi), (1/f_phi) * G_squared)

print("--- Representación Simbólica de la Ecuación (19) ---")
sp.pprint(ec_19)

# --- 2. Ejemplo Numérico (Ecuación de Klein-Gordon con fuente constante) ---
# Definimos el potencial: V(phi) = 0.5 * m^2 * phi^2 (Oscilador armónico)
m = 1.0
def dV_dphi(phi_val):
    return m**2 * phi_val

# Parámetros del acoplamiento
f_phi_val = 0.1
G_squared_val = 0.5  # Fuente constante
fuente = G_squared_val / f_phi_val

# Definimos la EDO: phi'' + dV/dphi = fuente
# Convertimos a un sistema de primer orden:
# y[0] = phi, y[1] = phi'
def sistema_edo(x, y):
    phi_val = y[0]
    dphi_val = y[1]
    # phi'' = fuente - dV/dphi
    d2phi_val = fuente - dV_dphi(phi_val)
    return [dphi_val, d2phi_val]

# Condiciones iniciales: phi(0) = 0, phi'(0) = 0
y0 = [0.0, 0.0]
x_span = (0, 20)
x_eval = np.linspace(x_span[0], x_span[1], 100)

# Resolvemos la ecuación
sol = solve_ivp(sistema_edo, x_span, y0, t_eval=x_eval)

print("\n--- Solución Numérica (phi(x)) ---")
print(f"Fuente (G^2 / f_phi): {fuente}")
print(f"Frecuencia de oscilación (m): {m}")
print(f"Valor de phi en x=10: {sol.y[0][50]:.4f}")

# Nota: Dado que hay una fuente constante, el campo oscilará
# alrededor del mínimo desplazado del potencial.
```
